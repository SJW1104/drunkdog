# SUNIVERSITY

대학생이 설문 응답자를 더 쉽게 확보하고, 서로의 설문에 참여하며 포인트를 순환시키는 **대학생 인증 기반 설문 커뮤니티**입니다.

## 해결하려는 문제

대학생은 논문, 팀 프로젝트, 창업, 학회, 캡스톤 등의 활동에서 설문조사를 자주 진행하지만 기존 도구만으로는 응답자를 직접 모집해야 합니다. 기업용 리서치 플랫폼은 비용과 사용 난도가 높고, 일반 커뮤니티는 응답자의 신뢰도와 설문 관리 기능이 부족합니다.

suniversity는 학교 인증과 포인트 시스템을 활용해 대학생이 서로의 설문을 돕고, AI를 통해 설문 설계와 결과 분석까지 지원하는 것을 목표로 합니다.

## 핵심 기능

- 대학생 회원가입 및 학교 인증
- 설문 등록, 검색, 필터링 및 참여
- 설문 참여 보상 포인트
- HOT, 마감 임박, 관심 분야 설문 추천
- 응답자 랭킹과 레벨
- AI 설문 문항 생성
- AI 결과 분석 및 인사이트 제공
- 설문 결과 기반 PPT 생성
- 포인트 내역과 기프티콘 교환

## MVP 범위

1. 로그인 및 회원가입
2. 학교 인증
3. 설문 등록
4. 설문 목록 및 상세 조회
5. 설문 참여
6. 포인트 획득과 사용
7. AI 설문 결과 분석

랭킹, 광고, 포인트 교환, PPT 생성 등은 MVP 이후 단계적으로 확장합니다.

## 프로젝트 구조

~~~text
suniversity/
├── frontend/   # React + Vite 웹 애플리케이션
├── backend/    # API 서버
└── ai/         # AI 설문 생성 및 결과 분석
~~~

## 프론트엔드 실행

~~~bash
cd frontend
npm install
npm run dev
~~~

기본 개발 서버는 http://localhost:5173 에서 실행됩니다.

## 프론트엔드 명령어

~~~bash
npm run dev
npm run build
npm run lint
npm run preview
~~~

## 환경 변수

frontend/.env.example을 복사해 frontend/.env를 만들고 API 주소를 설정합니다.

~~~env
VITE_API_BASE_URL=http://localhost:4000
~~~

## 브랜치 운영

- main: 안정 버전
- chore/frontend-scaffold: 새 설문 플랫폼 프론트엔드 기본 구조
- 기능 개발 브랜치는 feat/*, 환경 설정은 chore/*, 수정은 fix/* 형식을 사용합니다.
