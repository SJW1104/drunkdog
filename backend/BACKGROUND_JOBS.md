# 교환 자동 정리 작업

백엔드 서버 시작 시 교환 정리 작업이 함께 시작된다. 작업은 시작 직후 한 번 실행되고,
이후 기본 60초마다 다음 규칙을 적용한다.

- 양쪽 설문 중 빠른 마감의 24시간 전이 지나면 미완료 교환을 자동 만료한다.
- 만료된 교환에 보류 중이던 응답을 결과에서 제외한다.
- 마감·비공개·신고 무효화 등으로 진행할 수 없는 교환을 정리한다.
- 필수 응답 인원을 채울 수 없게 된 팀 교환을 취소한다.
- 목표 응답 수가 남은 자동 반복 설문을 다시 대기열에 넣고 매칭한다.

JSON 저장소 트랜잭션 안에서 처리하므로 한 번의 실행 결과가 통째로 저장된다. 동일한
상태에 여러 번 실행해도 중복 취소나 중복 신뢰도 이벤트가 생기지 않도록 기존 교환
정리 로직을 그대로 사용한다.

```powershell
$env:EXCHANGE_RECONCILE_INTERVAL_SECONDS="60"
```

값을 `0`으로 설정하면 주기 작업을 끌 수 있다. 서버 종료 시 진행 중인 작업은 안전하게
끝난 뒤 종료된다. 관리 및 개발 환경에서는 `POST /api/v1/exchanges/reconcile`을 호출해
즉시 수동 정리할 수도 있다.
