# 구형 재미·포인트 기능 처리 정책

최신 SUNIVERSITY 기획에서는 설문 제작·교환·결과 기능에 집중한다. 다음 기능은
기본적으로 비활성화되며 Swagger/OpenAPI 문서에도 노출되지 않는다.

- 포인트 지갑과 랭킹
- 출석 포인트와 보상 광고
- 포인트 상품, 교환 쿠폰
- 밸런스 게임과 관련 게시물
- 설문 참여 포인트 및 추가 보상 결제
- 포인트 기반 결과 구매

비활성화된 엔드포인트를 호출하면 HTTP `410 Gone`과
`LEGACY_GAMIFICATION_DISABLED` 오류 코드를 반환한다. 기존 구현과 JSON 필드는
데이터 이전 및 롤백을 위해 당분간 보존한다.

로컬에서 과거 동작을 검증해야 할 때만 다음 환경변수를 사용한다.

```powershell
$env:ENABLE_LEGACY_GAMIFICATION="true"
```

새 프론트엔드에서는 이 환경변수를 활성화하거나 구형 API를 호출하면 안 된다.
일반 설문 생성·수정 스키마는 포인트, 유료 결과, 밸런스 설문 입력을 허용하지 않으며
일반 설문 응답 영수증에도 포인트·잔액을 반환하지 않는다.
